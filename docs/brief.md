# hussh landing page redesign: brief

Unpaid 24h design task, closes Nov 6 2026 7:00 AM PT. Landing page only, any format. About 150 shortlisted candidates.

**Company:** hussh (formerly hushh.ai), Kirkland WA, one founder funding it (Manish Sainani, identity stolen 2021). Personal AI that works for the user, not advertisers. Voice on their company page is plain and self-critical.

**Products:** Agent One (private assistant for life admin, free for Americans), Puppy One (laptop with Agent One built in), Tag One (consent-based wearable, coming soon), Information Marketplace (profile and lock live; prices and payouts in design), PCHP (open consent protocol: verify, choose, share narrowly, keep a record).

**Chosen concept:** B "The handshake" as base with A's clarity. Hero is a live consent request from Agent One tied to the morning brief. Allow or decline, get a receipt. Every product shown as the same request shape. Status table instead of badges. Replace "100% On-Device" with "Your device first".
